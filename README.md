# Module Wiki Quiz

## Description

Quiz module for the Lutece Wiki plugin. Allows creating and managing quizzes associated with Wiki books.

## Features

- Create and manage quizzes per book
- Supported question types:
  - Multiple Choice (MCQ)
  - Single Choice (True/False)
  - Matching
  - Ordering
- Configurable time limit
- Configurable maximum attempts
- Customizable passing score
- Dashboard with statistics
- User attempt history
